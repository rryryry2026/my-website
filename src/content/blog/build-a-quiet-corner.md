这个博客诞生于一个再普通不过的夜晚。

窗外没有晚霞，只有对面楼里一扇还亮着的窗。我关掉几个不断弹出提醒的软件，忽然觉得，应该有一个地方，不催我更新，也不计算我写得好不好。

## 从一张空白纸开始

我想要的东西很简单：

- 打开就能读，不先登录，不先关广告；
- 背景有一点黄昏的颜色，但不要挡住文字；
- 文字排得舒展，代码块也清清爽爽；
- 写完一篇 Markdown，就能自动出现在列表里。

所以最后选了 Astro。它默认输出静态页面，不需要服务器常驻，也不需要为了一篇随笔搬运一整个框架。Tailwind 负责那些琐碎的间距和颜色，剩下的，就交给 CSS 慢慢打磨。

## 给文字留一点呼吸

阅读页面最重要的是安静。

我开始写这个博客的时候，最先定下来的不是首页，而是阅读页：正文多宽、行高多少、链接用什么颜色、引用怎样和正文区分开。

最后得到的感觉，应该像一杯放温了的水。没有很强烈的味道，但喝下去很舒服。

### 一段很轻的 CSS

毛玻璃卡片其实只需要很少几行：

```css
.glass {
  background: linear-gradient(
    145deg,
    rgba(47, 21, 16, 0.84),
    rgba(27, 12, 9, 0.72)
  );
  border: 1px solid rgba(255, 214, 171, 0.16);
  border-radius: 28px;
  backdrop-filter: blur(18px) saturate(125%);
  -webkit-backdrop-filter: blur(18px) saturate(125%);
}
```

再加一层很淡的内高光，玻璃就不会显得像一块塑料：

```css
.glass {
  box-shadow:
    0 24px 70px -20px rgba(10, 3, 2, 0.65),
    inset 0 1px 0 rgba(255, 239, 218, 0.07);
}
```

背景视频则固定在所有内容后面。记住给它加 `muted` 和 `playsinline`，不然大多数浏览器不会允许它自动播放。

```html
<video autoplay muted loop playsinline poster="/assets/bg-poster.jpg">
  <source src="/assets/bg.mp4" type="video/mp4" />
</video>
```

## 然后，慢慢写

技术只是容器。真正让一个角落变得像“自己的”的，是后来放进去的东西。

一次没有赶上的日落。一盆忘记浇水却还活着的花。某天突然想起的一句对白。它们不适合发在任何一个需要配九宫格的软件里，却刚好可以写在这里。

所以这个博客可能会很慢。

没有日更，没有热点，没有一定要完成的选题。想写的时候写，不想写的时候就让它空着。像一间不锁门的小屋，主人偶尔不在，但窗台上的灯一直亮着。

如果你恰好路过，就随便坐一会儿吧。
